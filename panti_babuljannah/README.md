# Sistem Informasi Panti Asuhan Babul Jannah

## 📌 Nama Mitra
Panti Asuhan Babul Jannah (Buntu Kanna, Kec. Ponrang, Kabupaten Luwu, Sulawesi Selatan).

## 🛠️ Tech Stack / Teknologi yang Digunakan
* **Bahasa Pemrograman:** PHP Native
* **Basis Data:** MySQL / MariaDB (XAMPP)
* **Desain Tampilan:** HTML5, CSS3, Google Fonts (Poppins)
* **Code Editor:** Notepad++

## 🚀 Cara Instalasi & Menjalankan di Lokal (XAMPP)
1. Pindahkan seluruh folder proyek `project-babuljannah` ke dalam direktori server lokal `C:/xampp/htdocs/`.
2. Aktifkan layanan **Apache** dan **MySQL** melalui **XAMPP Control Panel**.
3. Buka browser dan akses halaman `http://localhost/phpmyadmin/`.
4. Buat basis data baru dengan nama `db_babuljannah`, lalu pilih menu **Import** dan masukkan file dari folder `database/schema.sql`.
5. Akses aplikasi melalui browser:
   * **Halaman Utama / Publik:** `http://localhost/project-babuljannah/index.php`
   * **Halaman Login Admin:** `http://localhost/project-babuljannah/login.php`
